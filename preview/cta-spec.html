The rule

The radius is zero.

Nothing on this site is rounded. Not buttons, not cards, not inputs, not badges, not the basket counter.

A square corner is a decision that has to be held everywhere or it reads as an oversight. One rounded input in a checkout undoes the discipline of forty square components, because the eye finds the inconsistency before it finds the pattern.

It is a single token. Change it in one place and the whole site follows, which is exactly why it must not be overridden locally.

/* The only place radius is declared */
:root{
  --radius: 0;
}

/* Every component references it. Never a literal value. */
.btn{ border-radius: var(--radius); }
.card{ border-radius: var(--radius); }
.input{ border-radius: var(--radius); }

Hierarchy

Three levels, and only one primary per view.

How it is made

Primary

Carbon fill, Snow text. The one action the page exists for. Never more than one visible at a time. If a section needs two, one of them is secondary.

Secondary

Transparent with a hairline border. Sits beside the primary for the alternative path — usually more information rather than a competing action.

Quiet

An underlined text link at button scale. For onward navigation that is not an action. No border, no fill.

Minimum height is a touch target, not a visual choice. 48px is the accessible floor and the small variant only drops to 40px because it never appears alone on mobile.

States

Five, all of them required.

Ember is never a button background. It appears on focus outlines and on the quiet variant's hover, and nowhere else in this component.

On dark

Inverted, same geometry.

On a Carbon ground the primary becomes Snow fill with Carbon text. The secondary keeps a transparent fill and takes the dark hairline. Focus outlines switch to the lighter Ember so they stay visible.

Mobile

Full width below 600px, one action per row.

Buttons stack rather than sitting side by side. A 50/50 split on a narrow screen produces two targets that are both too small and reads as indecision about which one matters.

Labels

Sentence case, verb first, no more than four words.

Reference

The component, complete.

.btn{
  display: inline-flex; align-items: center; justify-content: center; gap: 10px;
  font-family: var(--body); font-weight: 500; font-size: 15px;
  letter-spacing: -.01em; line-height: 1;
  padding: 15px 30px;
  border-radius: var(--radius);   /* 0 */
  border: 1px solid transparent;
  background: var(--carbon); color: var(--snow);
  text-decoration: none; cursor: pointer;
  min-height: 48px;
  transition: background .18s ease, color .18s ease, border-color .18s ease;
}
.btn:hover        { background: var(--graphite); }
.btn:active       { background: #000; }
.btn:focus-visible{ outline: 2px solid var(--ember); outline-offset: 3px; }
.btn:disabled     { background: var(--hair); color: var(--graphite); cursor: not-allowed; }

.btn--line { background: transparent; color: var(--carbon); border-color: var(--hair); }
.btn--sm   { padding: 11px 20px; font-size: 13.5px; min-height: 40px; }
.btn--lg   { padding: 19px 38px; font-size: 16px;   min-height: 56px; }
.btn--block{ display: flex; width: 100%; }

No shadows. No gradients. No transforms on hover. No scale on active. The button changes colour and nothing else, because movement in a button is decoration and this is an instrument for buying a bed.
